# Feel Better: Penguin Emergency

A tiny phone-first browser game about a highly qualified penguin improving the situation.

## Play

GitHub Pages: https://goreadyconsulting.github.io/feelbetter/

## How it works

- Drag anywhere or use the left/right buttons to waddle.
- Catch good things like fish, cocoa, hugs, cake and tiny crowns.
- Avoid emails, alarm clocks, soggy socks, Mondays and unnecessary meetings.
- Build combos to charge **Maximum Waddle Authority**.
- Fill the Mood Rescue bar to complete the mission.
- Best score is saved locally on the device.

No dependencies, build step or backend required. The game runs from plain HTML, CSS and JavaScript.
